# أهلي نيوز — Admin
استضافة Node.js 18+.
1. npm install
2. اضبط متغيرات البيئة: ADMIN_PASSWORD=كلمة_مرور_قوية و ADMIN_TOKEN=رمز_عشوائي_طويل
3. npm start
4. افتح الموقع واضغط Admin.
اللوحة تضيف الأخبار مع الصور والانتقالات، وتحذفها. البيانات تحفظ في data.json والصور في public/uploads.
يفضل استخدام قاعدة بيانات دائمة وObject Storage عند الاستضافة الإنتاجية التي لا تحفظ الملفات المحلية.
